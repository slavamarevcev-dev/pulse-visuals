Pulse Visuals v1.1 - Fabric 1.21.11

ОБНОВЛЕНИЕ УЖЕ СОЗДАННОГО РЕПОЗИТОРИЯ:
1. Распакуйте архив.
2. В репозитории на GitHub: Add file -> Upload files.
3. Перетащите ТОЛЬКО папку src (файлы с теми же путями заменятся, новые добавятся).
4. Commit changes. Затем вкладка Actions -> дождитесь зелёной галочки.
5. Скачайте Artifacts -> pulse-visuals, замените старый jar в папке mods.

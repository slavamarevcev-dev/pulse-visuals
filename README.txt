Pulse Visuals - Fabric 1.21.11

КАК СОБРАТЬ JAR БЕЗ УСТАНОВКИ ЧЕГО-ЛИБО НА ПК:
1. Зарегистрируйтесь на github.com и создайте новый репозиторий (New repository).
2. Распакуйте этот архив. Откройте репозиторий -> Add file -> Upload files.
   Перетащите ВСЁ содержимое папки pulse-visuals (включая папки src и .github).
   Если папка .github не видна, включите показ скрытых файлов в проводнике.
3. Нажмите Commit changes.
4. Откройте вкладку Actions. Сборка запустится сама (3-5 минут).
   Если нет: Build mod -> Run workflow.
5. Откройте завершённый запуск, внизу в Artifacts скачайте pulse-visuals.
6. Распакуйте zip, jar положите в .minecraft/mods вместе с Fabric API 0.141.6+1.21.11.
7. В игре: Right Shift открывает ClickGUI.

Если сборка упала (красный крест), пришлите текст ошибки со строками "error:".
